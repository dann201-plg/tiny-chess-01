A tiny but strong chess engine in 4 KB of Python. PeSTO tapered evaluation, alpha-beta search with transposition table, quiescence and repetition detection, 200,000 nodes per move. It plays the make.fun tiny-chess-01 protocol over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
